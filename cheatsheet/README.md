# Markdown Cheat Sheet

[`AWS-Architecting-Cheatsheet.md`](AWS-Architecting-Cheatsheet.md) is the full cheat sheet in Markdown, covering all 17 modules of the "Architecting on AWS" course.

GitHub renders this file directly in the browser — just click it, no download needed.

Each module section includes:
- **Overview** — 2–4 sentences on what the module covers
- **Key Concepts** — the architectural ideas and decision criteria taught
- **AWS Services Covered** — every service mentioned, with a one-line description
- **Exam/Interview Tips** — crisp things to remember
