# AWS Service Reference Sheet

[`aws_services_cheatsheet.csv`](aws_services_cheatsheet.csv) lists every distinct AWS service mentioned across the course — 89 services in total.

| Column | Description |
|---|---|
| Service Name | Canonical AWS service name |
| Category | Standard AWS service grouping (Compute, Storage, Database, Networking, Security, etc.) |
| Use Case / Description | One-line summary of what it does / when to use it |
| Modules Covered | Which course module(s) mention it |

## Import into Google Sheets

1. Open [Google Sheets](https://sheets.google.com) and create a new blank spreadsheet.
2. `File → Import → Upload`, select `aws_services_cheatsheet.csv`.
3. Choose **Replace current sheet** (or **Insert new sheet**), separator type **Comma**, and import.
4. Select the header row and apply `Data → Create a filter` to make it easy to sort/search by Category or Module.

## Import into Excel

Open Excel → `Data → Get Data → From File → From Text/CSV` → select `aws_services_cheatsheet.csv` → Load.
