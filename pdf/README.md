# PDF Downloads

Two PDFs, for two different moments of studying:

## [`AWS-Quick-Revision.pdf`](AWS-Quick-Revision.pdf) — abstract, flash-card style

A 4-page cram sheet: one card per module, each with a one-line **core idea**, the **must-know services**, and 4-6 **key facts**. Built for the night before an exam or a last scan before an interview — not for learning the material the first time.

## [`AWS-Architecting-Cheatsheet.pdf`](AWS-Architecting-Cheatsheet.pdf) — full reference

A ~35-page printable version of the complete cheat sheet — same content as the [Markdown version](../cheatsheet/), with overview, key concepts, services, and exam tips per module. Use this for actual review, not just a glance.

Download either PDF directly from this folder (click the file, then "Download" or "View raw" on GitHub).

`quick-revision-source.md` is the Markdown source the quick-revision PDF was generated from, kept here for transparency and easy editing.
